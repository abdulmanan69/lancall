Set up a phone

Browsers only allow the microphone on secure pages. This phone system secures itself with its own certificate, which each device has to be told to trust once. After that there are no warnings, and calls ring reliably.

Download the certificate

Windows

  1. Open the downloaded lancall-ca.crt and choose Install Certificate.
  2. Pick Current User, then Place all certificates in the following store.
  3. Browse to Trusted Root Certification Authorities, finish, and confirm.
  4. Restart the browser.

Android

  1. Download the certificate.
  2. Open Settings and search for CA certificate (usually under Security, then Encryption and credentials, then Install a certificate).
  3. Choose CA certificate, accept the warning, and pick the downloaded file.

iPhone and iPad

  1. Download the certificate in Safari and allow the profile download.
  2. Open Settings, tap Profile Downloaded, and install it.
  3. Go to Settings › General › About › Certificate Trust Settings and switch on full trust for LAN Call Local CA.

Mac

  1. Open the downloaded file; it is added to Keychain Access.
  2. Find LAN Call Local CA, open it, expand Trust, and set Always Trust.

Linux

  1. Chrome: Settings › Privacy and security › Security › Manage certificates › Authorities › Import.
  2. Firefox: Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import.

Just trying it out?

You can skip all of this: open the phone page, and on the browser warning choose Advanced, then Proceed. Calls work, but notifications for calls in the background may not, and some phones refuse to connect at all without the certificate.
